# C-berry — single-page spa website

One-page site for **C-berry**, a 24-hour spa inside De Castle Hotel, G.R.A., Enugu.
Built with Vite + React + TypeScript. No router: the header links scroll to sections on the page.

**Sections:** Hero → Treatments → Gallery → Book a session / Find us → Footer.
Reviews, email and social links are deferred: see [`tickets/LATER-001`](tickets/LATER-001-contact-socials-reviews.md).

---

## Run it

```bash
npm install
npm run dev       # local dev server
npm run build     # type-check and build to dist/
npm run preview   # serve the production build locally
npm run images    # re-process photos after adding or swapping one
```

Deploy the `dist/` folder to any static host (Netlify, Vercel, Cloudflare Pages, S3).

## Project layout

```
index.html                  SEO meta, Open Graph, LocalBusiness JSON-LD, font links
scripts/process-images.mjs  resizes, grades and compresses every photo; edit SOURCES here
assets/                     original photos (C-berry's own)
assets/images/              original stock photos (Unsplash)
public/images/              generated WebP variants (don't edit by hand)
src/
  data/business.ts          name, phone, WhatsApp, address, hours: single source of truth
  data/services.ts          treatments, prices, durations, card copy
  data/imageManifest.json   generated by `npm run images`
  styles/tokens.css         design tokens: edit this block to rebrand
  styles/base.css           element defaults, buttons, layout helpers
  components/<Section>/     one folder per section, each with its own CSS
```

## Design tokens (`src/styles/tokens.css`)

Everything visual reads from the custom properties at the top of `tokens.css`.

| Group | Tokens | Notes |
|---|---|---|
| Colour | `--color-kola` `#1c1411` page · `--color-cocoa` `#2b1f1a` panels · `--color-shea` `#f4ebe1` text · `--color-clay` `#b8a596` secondary text · `--color-candle` `#e6ae6e` prices/focus · `--color-berry` `#a3345a` booking buttons | Berry is only ever a fill behind Shea text (5.6:1). Berry on Kola is 2.8:1, so never use it for text or thin lines. |
| Type | `--font-display` Cormorant Garamond *italic* · `--font-body` Hanken Grotesk · `--text-display` … `--text-label` | Sizes scale with the screen via `clamp()`. Four font weights total. |
| Space | `--space-1` … `--space-8`, `--gutter`, `--grid-gap`, `--section-pad`, `--container` | Gutter and section padding scale with the screen, like the reference site. |
| Shape | `--radius-image` 12px · `--radius-control` 0 | Only photographs are rounded; buttons and inputs stay square. |
| Motion | `--ease-out-expo`, `--dur-fast`, `--dur-base` | The only entrance animation is the hero's "candle warm-up". All motion is off under `prefers-reduced-motion`. |

## Images

Every photo runs through `scripts/process-images.mjs`, which:

- makes WebP copies at up to 480/800/1200/1600px wide (never enlarged);
- gives cooler photos a candle-coloured grade so stock and in-house shots match;
- writes their `src`, `srcset`, `width`, `height` and `alt` into `src/data/imageManifest.json`.

## Booking form

- Fields: name, email (optional), phone/WhatsApp, treatment, date, time, guests, notes.
- Each field is checked when the visitor leaves it and again on submit. Dates and times are checked in Enugu time, and any hour is allowed because C-berry is open 24/7.
- Every "Book …" button on a treatment pre-selects that treatment and scrolls to the form.
- While the Formspree endpoint is empty, a valid submit shows a panel offering to send the same details as a pre-filled WhatsApp message. Nothing is lost.

## Acceptance rubric (brief §7): self-score

Scored after an independent production review (Fable), fixes (Sonnet), and a live re-check in headless Chrome at 320/768/1024/1440/1920px.

| # | Criterion | Weight | Score | Justification |
|---|---|---|---|---|
| 1 | Fidelity to reference | 20% | 4 | Same dark warm ground, fluid type scale, screen-scaled gutters, square ghost buttons, 12px image radius and slow-settling easing as remedyplace.com; the hero is split rather than full-bleed because every supplied photo is portrait. |
| 2 | Brand distinctness | 15% | 5 | Candlelight palette plus Berry from the name, spa italics, 24/7 "open now" clock, WhatsApp-first contact, naira prices up front; no borrowed copy or marks. |
| 3 | Section completeness | 15% | 5 | Every section and §5 field in the owner-adjusted scope; Reviews, email and socials deliberately deferred to LATER-001. |
| 4 | Responsiveness | 10% | 4 | Measured zero horizontal overflow and zero overlap at all five widths; orphaned words are reduced with `text-wrap: balance/pretty`, but nobody visually checked the rendered pages. |
| 5 | Image handling | 10% | 4 | Fallback chain followed, one colour grade, alt/width/height/lazy on every image, source table above; six stock placeholders and four low-resolution owner photos remain. |
| 6 | Form correctness | 10% | 5 | Inline errors, first-invalid focus, service pre-select, disabled submit while pending, success, failure and not-configured states; the Formspree success path can't run until the endpoint is set. |
| 7 | Accessibility | 10% | 5 | AA contrast (computed), one h1, landmarks, labelled fields, full keyboard traversal including the lightbox, focus hand-off on every section link, reduced motion honoured. Not yet tested with a real screen reader or in Safari/Firefox. |
| 8 | Code quality | 5% | 5 | Tokenised CSS, one folder per section, no dead rules or specificity conflicts found, typed data as the single source. |
| 9 | Copywriting | 5% | 5 | Plain, specific to a 24-hour spa in G.R.A. Enugu; buttons name the action ("Book a facial", "Send on WhatsApp"). |

**Changed as a result of the review:** section links now move keyboard focus to the section they scroll to; the lightbox Tab cycle wraps without a stray stop; a defensive validation check is commented; low-resolution owner photos are flagged above.
